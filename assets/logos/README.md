# Vera Logos

Use the full Vera wordmark by default. Use the V mark when the available space cannot support the full wordmark.

## Downloads

| Mark          | Coral                                     | Dark                                     | White                                     |
| ------------- | ----------------------------------------- | ---------------------------------------- | ----------------------------------------- |
| Full wordmark | [PNG](./wordmark/vera-wordmark-coral.png) | [SVG](./wordmark/vera-wordmark-dark.svg) | [SVG](./wordmark/vera-wordmark-white.svg) |
| V mark        | [PNG](./v-mark/vera-v-coral.png)          | [PNG](./v-mark/vera-v-dark.png)          | [PNG](./v-mark/vera-v-white.png)          |

## Approved Logo Colors

| Variant | Color     | Use                                                      |
| ------- | --------- | -------------------------------------------------------- |
| Coral   | `#B5373A` | Light neutral backgrounds                                |
| Dark    | `#2D2926` | Light backgrounds where a neutral mark is preferred      |
| White   | `#FFFFFF` | Dark backgrounds or photography with sufficient contrast |

## Usage

- Use the version with the clearest contrast against the background.
- Preserve the artwork, proportions, and transparent background.
- Do not redraw, stretch, crop, outline, rotate, recolor, or add effects.
- Do not recreate the wordmark by typing it in Vera Custom.

These assets are proprietary to Vera Beauty Inc. and are provided for approved Vera work.
