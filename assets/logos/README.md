# Vera Logos

Use the full Vera wordmark by default. Use the V mark only when the available space cannot support the full wordmark, such as an avatar or compact application icon.

## Approved Colors

| Variant | Color     | Use                                                      |
| ------- | --------- | -------------------------------------------------------- |
| Coral   | `#B5373A` | Primary brand applications on light neutral backgrounds  |
| Dark    | `#2D2926` | Light backgrounds where a neutral mark is preferred      |
| White   | `#FFFFFF` | Dark backgrounds or photography with sufficient contrast |

## Usage Rules

- Preserve the artwork, proportions, and transparent background.
- Do not recolor, stretch, crop, outline, rotate, or apply effects.
- Choose the version with the clearest contrast against the background.
- Do not rebuild the logo by typing the wordmark in Vera Custom.

These assets are proprietary to Vera Beauty Inc. and are provided for approved Vera work.
